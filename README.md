# HTTPXscreenshot-viewer

A httpx screenshot viewer I made to make it easier to view all the subdomains with image output.
Basic viewer, just something I made quickly to view stuff, I might expand it more in the future

<img width="1834" height="952" alt="image" src="https://github.com/user-attachments/assets/94402c15-8e6f-4e7c-b6d3-79fda7e6ae31" />

## usage
- add -ss httpx for screenshots eg: ``httpx -l subs.txt -o httpx.txt -sc -title -fr -td -cl -ct -ss``
- run the Python to start the Flask app
- drag in the httpx.txt file
- specify the location of the screenshots output folder containing screenshots and responses
